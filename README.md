# نوسان‌باز PLAY

## فایل‌ها
- `index.html`: صفحه اصلی
- `admin.html`: صفحه جداگانه مدیریت و ورود
- `style.css`: طراحی و واکنش‌گرایی
- `app.js`: عملکردها و داده‌های محلی

## انتشار در GitHub Pages
همه فایل‌ها را در ریشه مخزن قرار بده. سپس در Settings → Pages شاخه `main` و پوشه `/ (root)` را انتخاب کن. صفحه اصلی با `index.html` و پنل از مسیر `admin.html` باز می‌شود. برای تست محلی می‌توانی `index.html` را با Live Server اجرا کنی.

## مهم درباره ورود مدیریت و بک‌اند
این نسخه بدون نصب چیزی در مرورگر اجرا می‌شود، اما فقط فرانت‌اند است و اطلاعات در `localStorage` همان مرورگر ذخیره می‌شوند. ورود سمت مرورگر امنیت واقعی ندارد؛ رمز داخل کد قابل مشاهده است و داده‌ها بین دستگاه‌ها همگام نمی‌شوند. GitHub Pages بک‌اند اجرا نمی‌کند. برای ورود امن و اطلاعات مشترک آنلاین باید یک سرویس بک‌اند را یک‌بار تنظیم کرد؛ نمی‌توان آن را امن و واقعی کرد بدون هیچ پیکربندی یا دسترسی حساب.
