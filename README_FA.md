# TRADE NOVA — نسخه به‌روزشده

فایل‌ها: `index.html`, `style.css`, `app.js`.

برای اجرا، هر سه فایل را کنار هم نگه دار و `index.html` را باز کن یا با VS Code از Live Server استفاده کن. نیازی به Python یا Node.js ندارد.

امکانات: نمودار کندلی ساخته‌شده با Canvas، بازه‌های زمانی نمایشی، سیگنال‌های BUY/SELL، انتخاب اهرم تا 100×، محاسبه ارزش معامله و شبیه‌سازی سود و زیان بر اساس تغییر قیمت. پنل مدیریت وجود ندارد.

**مهم:** این پروژه یک شبیه‌ساز فرانت‌اند است. قیمت‌ها ساختگی و معاملات، اهرم، موجودی، واریز و برداشت مجازی‌اند؛ به صرافی یا بازار واقعی وصل نیست و پول واقعی جابه‌جا نمی‌کند.
